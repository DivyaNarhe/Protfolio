Create a simple, elegant, modern, and minimalistic personal portfolio website for **Divya Shantaram Narhe**, a Software Developer and WordPress Developer based in Pune, India.

## Overall Design Direction

Design the website with a **premium minimalist aesthetic** inspired by modern developer portfolios such as Linear, Vercel, Stripe, and Apple.

The design should feel:

* Clean
* Professional
* Elegant
* Modern
* Minimal
* Technical but approachable
* Spacious with excellent visual hierarchy
* Premium without unnecessary visual effects

Use a **light theme** with an off-white/white background, dark charcoal typography, subtle gray borders, and one sophisticated accent color. Keep the color palette restrained.

Use generous whitespace, clean typography, subtle shadows, rounded corners, thin borders, and carefully aligned content.

Avoid:

* Excessive gradients
* Heavy animations
* Glassmorphism everywhere
* Cluttered layouts
* Stock photos
* Excessive icons
* Large decorative illustrations
* Unnecessary UI elements

# TYPOGRAPHY

Use a modern premium sans-serif font.

Preferred:
**Inter**, **Manrope**, **Satoshi**, or **DM Sans**.

Use:

* Large bold typography for headings
* Medium-weight body text
* Small uppercase labels for section numbers
* Comfortable line height
* Strong hierarchy

Do not use decorative serif fonts.

---

# COLOR SYSTEM

Use a restrained palette:

Background: warm white / off-white
Primary text: near-black / charcoal
Secondary text: muted gray
Borders: very light gray
Accent: sophisticated blue or indigo

Keep the accent color limited to buttons, links, active states and small highlights.

---

# INTERACTIONS & ANIMATIONS

Use subtle animations only.

Include:

* Smooth scrolling
* Fade-up reveal on section entrance
* Subtle hover effect on project cards
* Slight button movement on hover
* Animated underline for navigation links
* Smooth navbar transition on scroll

Animations should be fast, subtle and professional.

Do NOT use:

* Excessive parallax
* Large spinning animations
* Distracting particle backgrounds
* Cursor-following effects
* Excessive 3D effects

---

# RESPONSIVE DESIGN

The website must be fully responsive.

Desktop:
Use spacious two-column layouts and large typography.

Tablet:
Adapt grids and spacing naturally.

Mobile:
Use a clean hamburger menu.
Stack all content vertically.
Maintain generous spacing.
Make CTA buttons easy to tap.
Ensure typography remains readable.

---

# UX REQUIREMENTS

The portfolio should immediately communicate:

**Who she is → What she does → What she has built → Her technical expertise → Her experience → How to contact her.**

Prioritize readability and storytelling over decoration.

The entire website should feel like a **senior developer's premium portfolio**, not a generic template.

Use consistent spacing, alignment, typography, border radius and component styling throughout the website.

Make the final design **simple, elegant, modern, minimalistic, professional and highly polished.**
